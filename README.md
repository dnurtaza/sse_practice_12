# Smart Campus Room Availability Checker

Smart Campus application designed to check and manage room availability, handle bookings, and validate constraints.

## Project Structure
- `src/` — React components and business logic
- `tests/` — AutomateSd test suite (Vitest)
- `AGENTS.md` — Guidelines and safety constraints for AI agents

npm test
